1. 화면 설계 개요

BookLog는 베스트셀러와 스테디셀러 50권의 초기 데이터를 기반으로 독서 기록을 관리하는 단일 화면 중심의 CRUD 앱이다. 실제 구현 화면은 상단 히어로, 통계 카드, 왼쪽 입력 폼, 오른쪽 책 목록 영역으로 구성된다.

PC 화면에서는 입력 폼과 책 목록이 좌우로 배치되고, 태블릿과 모바일에서는 화면 폭에 맞춰 자연스럽게 2열 또는 1열로 전환된다.

본 문서는 실제 구현된 BookLog 화면을 기준으로 주요 영역의 배치와 사용자 흐름을 시각적으로 정리한다.

4. 히어로 영역

READING LOG APP BookLog

베스트셀러와 스테디셀러 50권을 기반으로 책을 검색하고, 독서 상태와 별점, 메모를 관리할 수 있는 독서 기록 앱입니다.

  • 배경 이미지 위에 어두운 오버레이를 적용한다.
  • 히어로 하단에 통계 카드가 바로 이어진다.
  • 설명 문구는 PC와 모바일 모두에서 잘리지 않도록 제한된 너비 안에서 줄바꿈된다.
  • rounded corner는 유지하되, 전체 높이는 통계 카드가 빠르게 보이도록 compact하게 구성한다.

11. 반응형 화면 설계

PC

  • 히어로와 통계 카드는 상단 전체 폭으로 표시된다.
  • 본문은 왼쪽 입력 폼, 오른쪽 책 목록의 2단 구조를 사용한다.
  • 책 카드는 3열 그리드로 표시된다.

태블릿

  • 화면 폭에 따라 폼과 목록이 2단 또는 세로 배치로 전환된다.
  • 책 카드는 2열 그리드로 표시된다.

모바일

  • 히어로, 통계 카드, 입력 폼, 검색/필터/정렬, 책 목록, 페이지네이션이 세로로 배치된다.
  • 입력 폼 내부 필드는 1열로 내려간다.
  • 책 카드는 1열로 표시된다.

12. 사용자 흐름

1. 앱 접속
2. 도서 목록 조회
3. 검색 / 필터 / 정렬 / 페이지 이동
4. 도서 추가 또는 기존 도서 수정
5. 삭제 확인 모달 표시
6. 취소: 모달 닫기 / 삭제: DELETE API 호출 후 목록 갱신
