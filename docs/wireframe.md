# BookLog 와이어프레임

## 1. 화면 설계 개요

BookLog는 베스트셀러와 스테디셀러 50권의 초기 데이터를 기반으로 독서 기록을 관리하는 단일 화면 중심의 CRUD 앱이다. 실제 구현 화면은 상단 히어로, 통계 카드, 왼쪽 입력 폼, 오른쪽 책 목록 영역으로 구성된다.

PC 화면에서는 입력 폼과 책 목록이 좌우로 배치되고, 태블릿과 모바일에서는 화면 폭에 맞춰 자연스럽게 2열 또는 1열로 전환된다.

본 문서는 실제 구현된 BookLog 화면을 기준으로 주요 영역의 배치와 사용자 흐름을 시각적으로 정리한다.

## 2. 전체 화면 구조

| 영역 | 실제 UI 구성 |
| --- | --- |
| 히어로 | `READING LOG APP`, `BookLog`, 앱 설명, 배경 이미지와 어두운 오버레이 |
| 통계 카드 | 전체 책 수, 읽고 싶은 책, 읽는 중, 완독, 중단 |
| 본문 왼쪽 | 새 책 추가/수정 폼 |
| 본문 오른쪽 | 책 목록 헤더, 검색/필터/정렬, 3열 카드 그리드, 페이지네이션 |
| 삭제 모달 | overlay dim + blur, 삭제 확인 문구, 취소/삭제 버튼 |

## 3. 메인 화면 와이어프레임

### 3.1 상단 영역

- 히어로 영역에는 작은 라벨 `READING LOG APP`, 큰 제목 `BookLog`, 설명 문구를 표시한다.
- 설명 문구는 “베스트셀러와 스테디셀러 50권을 기반으로 책을 검색하고, 독서 상태와 별점, 메모를 관리할 수 있는 독서 기록 앱입니다.”를 사용한다.
- 히어로 하단에는 통계 카드 5개가 바로 이어진다.

### 3.2 통계 카드 대표 값

| 항목 | 값 |
| --- | ---: |
| 전체 책 수 | 50 |
| 읽고 싶은 책 | 10 |
| 읽는 중 | 10 |
| 완독 | 23 |
| 중단 | 7 |

### 3.3 PC 기준 본문 배치

- 왼쪽에는 compact한 책 추가/수정 폼을 배치한다.
- 오른쪽에는 책 목록 영역을 배치한다.
- 책 목록 영역 상단에는 `책 목록`, `나의 BookLog`, `50권 중 9권 표시`를 보여준다.
- 검색/필터/정렬은 `제목 또는 저자 검색`, `전체 상태`, `전체 카테고리`, `최신순` 순서로 배치한다.
- 카드 목록은 PC에서 3열 그리드로 표시하고, 아래에 페이지네이션을 둔다.

## 4. 히어로 영역

- 배경 이미지 위에 어두운 오버레이를 적용한다.
- `READING LOG APP` 라벨과 `BookLog` 제목이 첫 화면에서 명확히 보이게 한다.
- 설명 문구는 제한된 너비 안에서 자연스럽게 줄바꿈한다.
- 히어로 하단에 통계 카드가 빠르게 보이도록 높이를 compact하게 유지한다.

## 5. 통계 카드 영역

- 전체 책 수, 읽고 싶은 책, 읽는 중, 완독, 중단을 각각 독립된 카드로 표시한다.
- PDF에서는 5개 카드가 가로로 배치되되, 폭이 부족하면 3개 + 2개 형태로 자연스럽게 줄바꿈된다.
- 카드 크기는 화면 상단을 과하게 차지하지 않도록 compact하게 구성한다.

## 6. 검색/필터/정렬 영역

| 순서 | UI 요소 | 동작 |
| --- | --- | --- |
| 1 | 제목 또는 저자 검색 | 제목과 저자 기준으로 검색한다. |
| 2 | 전체 상태 | `want`, `reading`, `done`, `paused` 상태를 필터링한다. |
| 3 | 전체 카테고리 | 국내 소설, 해외 소설, 에세이 등 카테고리를 필터링한다. |
| 4 | 최신순 | 최신순, 별점 높은순, 제목순, 완독일순으로 정렬한다. |

- 검색, 필터, 정렬 조건이 변경되면 현재 페이지는 1페이지로 이동한다.
- 정렬은 백엔드 query가 아니라 프론트엔드 상태에서 처리된다.

## 7. 책 추가/수정 폼 영역

폼은 실제 구현 UI처럼 다음 순서로 구성한다.

1. 상단 텍스트: `새 책 추가`, `독서 기록을 남겨보세요`
2. 제목 / 저자
3. 카테고리 / 상태
4. 별점
5. 시작일 / 완독일
6. 메모
7. `책 추가` 버튼

- 제목/저자, 카테고리/상태, 시작일/완독일은 PC에서 2열로 배치된다.
- 별점은 좁아 보이지 않도록 별도 행으로 배치된다.
- 수정 모드에서는 같은 폼에 기존 데이터가 채워지고, 상단 문구와 버튼이 수정 모드에 맞게 바뀐다.
- 모바일에서는 모든 입력 항목이 1열로 내려간다.

## 8. 책 목록 카드 영역

책 카드는 실제 구현 UI처럼 다음 정보를 compact하게 표시한다.

- 카드 상단: 상태 배지, 평점 `4.5 / 5`
- 책 제목
- 저자 / 카테고리
- 시작일 / 완독일
- 메모
- 하단 버튼: 수정 / 삭제

PC에서는 3열 카드 그리드로 표시한다. 태블릿에서는 2열, 모바일에서는 1열로 전환된다. 긴 제목은 1~2줄까지만 보이고, 저자명/카테고리/메모는 말줄임 처리된다.

## 9. 페이지네이션 영역

- 책 카드 목록 아래에 배치된다.
- 예시 형태는 `이전`, `1`, `2`, `3`, `다음` 버튼이다.
- 현재 페이지 버튼은 활성 상태로 표시된다.
- 검색, 필터, 정렬 조건 변경 시 1페이지로 이동한다.

## 10. 삭제 확인 모달

- overlay에는 dim과 blur 처리를 적용한다.
- 모달은 가로 중앙에 정렬하고, 세로 위치는 viewport 기준 중앙보다 살짝 위쪽에 표시한다.
- 문구는 `삭제 확인`, `이 책 기록을 삭제할까요?`, `삭제하면 되돌릴 수 없습니다.`, `선택한 책 제목 / 저자`를 사용한다.
- 버튼은 `취소`, `삭제`를 제공한다.
- 취소를 누르면 모달만 닫고, 삭제를 누르면 기존 DELETE API 호출 후 목록을 갱신한다.

## 11. 반응형 화면 설계

### PC

- 히어로와 통계 카드는 상단 전체 폭으로 표시된다.
- 본문은 왼쪽 입력 폼, 오른쪽 책 목록의 2단 구조를 사용한다.
- 책 카드는 3열 그리드로 표시된다.

### 태블릿

- 화면 폭에 따라 폼과 목록이 2단 또는 세로 배치로 전환된다.
- 책 카드는 2열 그리드로 표시된다.

### 모바일

- 히어로, 통계 카드, 입력 폼, 검색/필터/정렬, 책 목록, 페이지네이션이 세로로 배치된다.
- 입력 폼 내부 필드는 1열로 내려간다.
- 책 카드는 1열로 표시된다.

## 12. 사용자 흐름

1. 앱에 접속한다.
2. 도서 목록을 조회한다.
3. 검색, 필터, 정렬, 페이지 이동을 사용한다.
4. 도서를 추가하거나 기존 도서를 수정한다.
5. 필요한 경우 삭제 버튼을 클릭한다.
6. 삭제 확인 모달에서 취소 또는 삭제를 선택한다.
